# URL-Shortener Community Edition

Open-core community edition of the URL shortener: core domain, REST server,
Java client SDK, and the Vaadin admin UI (`urlshortener-{core,server,client,ui}`).

> Full build/usage documentation follows with the 00.18.00 cycle (P070).
