# Release 00.18.00 — open-core edition split

_2026-08-31_

Restructuring cycle on top of 00.17.00: the project is now an **open-core
code base** with two editions. This repository is the **Community Edition**
(EUPL-1.2) with a fresh git history; the former monorepo is archived as
`url-shortener-legacy`. Commercial features live in the separate Enterprise
Edition repository and plug into the seams described below — community
sources are never changed for a new commercial feature.

## Edition split

- **Community** (this repo): `urlshortener-core`, `urlshortener-server`,
  `urlshortener-client`, `urlshortener-ui` — the full shortener with
  security (jCustos), statistics, import/export, blocklist and admin UI.
- **Moved to Enterprise**: CLI, MCP server, audit export, and the whole
  link-meta family (campaigns, first-class tags, labels). The community
  server keeps the persistence-compat types so existing stores stay
  readable; the data lies dormant without the plug-ins.

## Plug-in seams (ServiceLoader)

- **UI SPI** `com.svenruppert.urlshortener.ui.vaadin.extension`:
  `FeatureContribution` — dynamic routes, drawer/navbar entries, link-form
  and link-details slots.
- **Server SPI** `com.svenruppert.urlshortener.api.extension`:
  `HandlerContribution` + `ServerContext` (url-mapping, link-meta,
  statistics, preferences stores and `StorageAdmin`),
  `LinkLifecycleContribution` (create-time metadata, delete cascades, list
  filters), `StartupContribution` (runs before the stores open),
  `MaintenanceGate` + filter (503 quiesce window on the admin API).
- Boundary tests in server and ui fail the build if community sources ever
  reference `urlshortener.enterprise`.
- New admin permission `backupManage` for the enterprise backup endpoints.

## Changes

- **Uniform Maven coordinates**: every artifactId now equals its directory
  name (`urlshortener-core`, `urlshortener-server`, `urlshortener-client`,
  `urlshortener-ui`; reactor `urlshortener-community-root`).
- **HttpStatus sweep**: every status code the server emits goes through the
  `HttpStatus` enum; shortlink resolution deliberately answers **302**
  (per-hit statistics, mutable targets — no cacheable 301).
- **Full-backup seam**: `EclipseStore.issueFullBackup(Path)` exports a
  bootable storage directory; `StorageAdmin` exposes it to plug-ins.
- **Dev seam for plug-in work**: `jetty:run` accepts
  `-Djetty.extraClasspath` to overlay enterprise plug-ins onto the UI.

## Dependencies

- jCustos **00.81.00-SNAPSHOT** — adds the public full-backup export on
  `EclipseStoreJCustosStorage`. Note: this version is not yet published
  to the registry; building from source currently requires a local
  jCustos install. The released server fat-jar bundles it, so runtime
  artifacts are unaffected. The pin moves to the final jCustos release
  in the next cycle.

## Release chain

Community artifacts are published to the Gitea Maven registry
(`https://git.jsentinel.eu/api/packages/sven.ruppert/maven`); Maven Central
publication follows once the namespace onboarding is completed.

No production deployment: the 3g3.eu host keeps running 00.15.00 (deploy
freeze of 2026-08-18).
