# Release 00.21.00 — GUI makeover, link passwords, API hardening

_2026-11-01_

One release on top of 00.18.00 that bundles the work of three planned
windows: the 00.19.00 analytics seams, the 00.20.00 API hardening and
jCustos migration, and the 00.21.00 GUI makeover. The 00.19.00 and
00.20.00 lines were never cut as their own releases; their scope ships
here. This repository is the **Community Edition** (EUPL-1.2).

## GUI makeover (jSentinel design on Vaadin Aura)

- Every admin view reskinned to the jSentinel design system on the Aura
  theme: Overview, Create / BulkCreate, the details dialog, Login / Setup,
  Profile and user management, Statistics / Statistics-Detail / Audit, and
  the About page.
- New application shell: a grouped drawer navigation with an identity
  footer (avatar, name · role, color-scheme toggle, Profile, Sign out) and
  a navbar quick-search pill.
- Global **Cmd/Ctrl-K quick-search** palette that finds links by short code
  or target URL and opens the details dialog.
- The store indicator now **color-codes the backend connection**: green for
  EclipseStore, blue for in-memory, red for disconnected, amber while a
  connection attempt is in progress (probed off the UI thread via push).
- CSS cleanup: the Aura theme defines no `--lumo-*` custom properties, so
  all dead `var(--lumo-*)` declarations were removed and the remaining
  styles rewritten in fixed units / `color-mix` so they render in both
  light and dark. Spacing fixes for the Overview paging / Import / Export
  bar, the login "Remember me" checkbox and the delete-dialog actions.

## Link password protection

- Optional **per-link password** alongside the existing expiry; a protected
  link shows a badge and serves a localized challenge page on redirect
  before resolving the target.

## API correctness and hardening

- Short links now answer **HEAD** instead of rejecting it.
- Malformed JSON request bodies get a **400** instead of a silently closed
  connection (Jackson 3 throws unchecked — routed through the body-parse
  helpers).
- Corrected status codes and the headers they must carry; an aborted export
  now **fails loudly** instead of returning 200.
- `toggleActive` normalizes the alias like every other lookup.

## Analytics seams (for the Enterprise edition)

- Permission wiring and i18n for the enterprise analytics reports, and the
  **campaign-analyst** role with its assignment seam (row-level scoping
  lives in the Enterprise edition).

## Changes

- The signed security-event stream moved **out of community** into an
  Enterprise plug-in; the community server keeps only the SPI seam.
- Internal cleanup: fully-qualified class names replaced by imports.

## Dependencies

- **jCustos 00.82.00** (security framework, `eu.jsentinel`), replacing the
  volatile jSentinel 00.81.00-SNAPSHOT pin of 00.18.00. Resolved from the
  in-house registry `repo.jsentinel.eu` (releases), with Maven Central as a
  cross-check.
- Vaadin 25.2.3, EclipseStore 4.1.0, ICU4J 78.3.

## Release chain

Community artifacts are published to the jSentinel Maven registry; the
repository is mirrored to GitHub.

No production deployment: the 8g8.eu / 3g3.eu host keeps running
00.16.00-SNAPSHOT (deploy freeze of 2026-08-18).
